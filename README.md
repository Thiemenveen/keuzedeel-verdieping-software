# Verdieping Laravel Starter Kit

In dit project ga ik de Laravel Vue Starter Kits met elkaar vergelijken om inzicht te krijgen in de verschillen tussen de kits, hoe deze verschillen van toepassing zijn tijdens het ontwikkelen van software en welke kit het meest geschikt is voor het maken van een webshop. Na de analyse en vergelijking maak ik een keuze voor de starter kit die naar mijn verwachting het beste aansluit bij het ontwikkelen van een webshop. Vervolgens gebruik ik deze kit om een werkende webshop te realiseren.

## De software die ik ga vergelijken

**- Laravel React Starter Kit**
**- Laravel Vue Starter Kit**
**- Laravel Livewire Starter Kit**
**- Laravel Svelte Starter Kit**
